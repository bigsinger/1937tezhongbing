# 最终归档发布说明

本仓库的最终冻结版本发布于 2026-08-10。GitHub 仓库归档后保持只读，代码、
文档、Git LFS 内容与 Release 下载仍可继续获取。

## 普通玩家

从 [最终归档 Release](https://github.com/bigsinger/1937tezhongbing/releases/tag/archive-2026.08.10)
按需下载：

- `1937-Mod-portable.zip`：原版现代增强版，解压后运行
  `选择关卡.ps1` 或 `启动游戏-窗口模式.cmd`；
- `1937-Remake-portable.zip`：Godot 现代复刻版，解压后运行
  `Play-1937-Remake.cmd`；
- `1937-MapEditor-portable.zip`：自包含地图编辑器、素材库和十二关地图，
  解压后运行 `1937MapEditor.exe`。

每个 ZIP 都有同名 `.sha256` 文件。下载后可用以下命令核对：

```powershell
Get-FileHash .\1937-Mod-portable.zip -Algorithm SHA256
```

## 开发者与二次创作

需要完整历史和 Git LFS 资源时使用：

```powershell
git lfs install
git clone https://github.com/bigsinger/1937tezhongbing.git
```

- Mod/Patch/SDK：Visual C++ x86 与 PowerShell 构建链见 `Patch/README.md`；
- Remake：安装 Godot 4.7.1 和 .NET 10 后运行
  `Remake/tools/Build-Playable.cmd`；
- MapEditor：安装 .NET 10 SDK 后运行
  `dotnet build MapEditor/MapEditor.slnx -c Release`。

剧情等历史内容不因本项目的 MIT 许可证而被重新授权，使用者应自行确认适用的
授权与法律条件。

## 冻结范围

- `Mod/`：十二关完整可玩资源与现代兼容层；
- `Remake/`：Godot 工程、资源转换工具、测试与便携构建脚本；
- `MapEditor/`：可视化地图/任务查看、编辑、另存与内容包导出；
- `Patch/`、`SDK/`：兼容补丁、逆向研究结论、稳定地址与扩展接口；
- `doc/`、`Screenshots/`：设计、验证报告、使用方法和效果截图。

个人存档、运行时索引、用户配置、遥测日志以及本机构建缓存不属于冻结发布内容。
