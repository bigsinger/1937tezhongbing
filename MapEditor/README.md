# 《1937特种兵》地图与任务编辑器

这是面向原版魔改和社区关卡制作的现代编辑器。它可以：

- 新建任意尺寸的网格地图；
- 分别编辑地表、视线障碍、移动障碍、事件和人工通行修正五类图层；
- 放置敌军、玩家、门、物品和任务点；
- 用任务 ID、触发器、目标对象、数量、失败条件和后继任务组成任务链；
- 只读解析原版 `VWL1/SLIST1` VWF，导入五个图层和场景对象；
- 保存可读、可进行 Git 差异比较的 `*.m37map.json`，并导出 `*.m37pack.json`。

## 运行

已经发布过本地版本时，右键运行 `启动地图编辑器.ps1`。开发环境可直接运行：

```powershell
dotnet run --project .\MapEditor.App\MapEditor.App.csproj
```

编辑器不会回写或覆盖原版 VWF。现代 JSON 任务包是稳定的中间格式；后续向原版二进制 VWF 反向导出的工作应在格式字段全部验证后单独实现。
