# 《1937特种兵》地图编辑器

面向原版关卡查看、修改和社区新关卡制作的可视化编辑器。

## 最简单的使用方法

1. 运行 `启动地图编辑器.ps1`；
2. 点击顶部“打开原版/工程地图”，选择 `Mod` 中任意
   `1937m000.vwf`—`1937m011.vwf`；
3. 默认选中素材库第一项“鼠标箭头（仅查看）”，浏览地图不会添加对象；
   需要编辑时再从左侧选择其他素材，在地图上单击放置；
4. 点击“另存为新地图”保存为 `*.m37map.json`；如果地图来自 VWF，
   也可点“安全另存为可运行 VWF”，先审查差异再输出游戏可读取的副本；
5. 新建社区关卡时选择“导出 Remake 原生内容包”，生成 `.m1937pack`，或选择
   “在 Remake 中试玩当前地图”在隔离临时目录直接启动验证。

导入原版 VWF 始终是只读操作，原生另存拒绝选择导入源本身。图层、对象列表和
任务链仍然可以编辑，但都放在折叠区或右侧高级页中，不影响简单流程。

## 已支持

- 直接打开和预览原版 VWF、打开现代 `*.m37map.json`；
- 直接读取 VWF 活物巡逻点，并按移动障碍层计算实际八方向路径；
- 默认显示全部路线和低开销运动预览；静态路线与动态标记分层绘制；
- 单击活物或在对象表选中后，高亮它避开墙体后的完整轨迹、路线点顺序和运动位置；
- 素材列表以“鼠标箭头（仅查看）”为第一项且默认选中，打开地图安全预览；
- 12 张原版地图及其场景对象的完整预览；
- 1,037 个角色、树木、院墙、房屋、门、车辆、障碍和物品素材；
- 45 套地表图块；
- 地表、视线障碍、移动障碍、事件和通行修正五类图层；
- 对象放置、选择、删除和属性表；
- 任务 ID、触发器、目标、数量和后继任务；高级页可直接编辑 Sidecar
  身份、选择关号/原版骨架、依赖、可选/失败目标、数据库对象、区域和期限；
- 完整 Ctrl+Z/Ctrl+Y Undo/Redo 命令历史；
- Error/Warning/Info 问题面板；检查接缝、footprint、孤立区、不可达任务、
  窄通道、巡逻 A* 中间段、等速时间轴会车、出生威胁和前景排序，
  单击问题直接定位；
- 选中敌军后显示随 8 方向变化且被 L2 障碍截断的视线扇形，并叠加攻击、
  听觉和警报边界；AI 等级与难度可推演，界面明确标记数值来源；
- 从玩家出生点计算可达热图，并向所选对象或首个任务目标绘制最短路线；
- 地表、语义层、网格、对象、巡逻与运动标记只绘制当前可见视口；
  120×200、1,470 对象地图在 100% 缩放实测仅访问 1,643 格、
  绘制 37 对象，截图帧约 11.8 ms；
- JSON 地图工程和任务包导出；
- 以 Remake 共用 schema 确定性导出 `.m1937pack`，并在写出前执行路径、哈希、
  尺寸、实体、任务和不可执行载荷策略校验；
- 一键在独立临时 `UserCampaigns` 中启动 Remake 试玩，不修改玩家正式内容库、
  存档或原版 VWF；
- 多选/框选/对齐/分布/复制/批量属性，地形画笔/矩形/填充；
- 巡逻点拖拽/插入/删除，对象组合筛选，图层锁定/透明度/独显/预设；
- 原子自动保存恢复、任务依赖图/状态码映射、AI 协同和玩家时间轴；
- 跨地图区域库、语义 diff/三方合并、带 API 门禁的导入导出插件；
- 正式 `*.m1937mission.json` 的数据库 ID、区域、依赖、计数、失败和
  超时往返；
- 一键生成 README、SVG 缩略图、故事章节、验证摘要和发布清单；
- 原生 VWF 安全另存：保持已知版本、scene 数、记录长度和巡逻容量，
  同步五层网格、世界/参考坐标、动态占用和两套巡逻点；
- 写入前显示二进制与语义 diff；临时文件重解析通过后才原子替换输出，
  已有输出自动保留 `.bak`。

原生另存当前有意拒绝新增/删除 scene 或改变巡逻点数量，因为这些操作会改变
原版变长记录布局。此类设计仍可保存为 JSON 工程或通过关卡包向导重新部署，
不会冒险生成半损坏 VWF。

`tools/VwfMissionBuilder` 和 `tools/VwfBlueprintComposer` 继续作为格式研究
工具保留，可同步处理对象坐标、巡逻数组和五层网格；但 MOD 不再发布由它们
生成的扩展关。任何候选都必须经过完整原版实机任务闭环，不能仅凭离线 A*
或文件可载入就登记为可玩关卡。

普通制作者不必手写这些 JSON。选择“文件 → 新建可运行关卡包向导”后可以：

1. 选择 `redeploy` 或 `composite`、源 VWF 和 1—12 关任务骨架；
2. 从真实 scene 列表选择玩家、敌军、目标、接头与撤离对象；
3. 设置出生安全距离、巡逻距离、全图可达率及合成块大小；
4. 一键在 `E:\1937\mission-wizard` 生成隔离候选、局部预览和验证报告；
5. 审查 SHA-256 后显式勾选人工确认，才写入
   `baseline-acceptance.json` 并发布到 `Mod`；
6. 同时导出 `mission-route.draft.json`，代码评审后才能并入 SDK 路由表。

向导不会覆盖源 VWF；首次候选构建预期会因“尚未接受哈希”停止在发布边界，
这是确定性保护的一部分。完整验收记录见
[`docs/地图分析与关卡包向导验收报告.md`](docs/地图分析与关卡包向导验收报告.md)。

新关模板位于 `Missions/_template`，完整流程和“能加载/能完成/可发布”的
验收边界见
[`doc/关卡制作与验证方法论.md`](../doc/关卡制作与验证方法论.md)。

素材统一放在相对目录 `Assets/Original`，通过 `catalog.json` 分类索引。
如重新运行资源解析工具，可使用：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\Sync-OriginalAssets.ps1
```

## 开发与验证

```powershell
dotnet build .\MapEditor.slnx -c Release
$env:M1937_TEST_VWF = '..\Mod\1937m000.vwf'
$env:M1937_MAPEDITOR_ASSETS = '.\Assets\Original'
dotnet run --project .\MapEditor.Tests\MapEditor.Tests.csproj -c Release
```

设置 `M1937_TEST_VWF_DIRECTORY` 为 `Mod` 后，测试会对
`1937m000.vwf`—`1937m011.vwf` 执行无修改字节等价 round-trip，并验证
对象/参考坐标/动态占用/巡逻同步以及损坏、越界、scene 增删和容量变化拒绝。
完整结果见
[`docs/原生VWF安全写回测试报告.md`](docs/原生VWF安全写回测试报告.md)。
本轮编辑效率、任务/AI、协作、sidecar 和本地发布验收见
[`docs/持续改进功能验收报告.md`](docs/持续改进功能验收报告.md)。
Remake 原生包的目录、安装、升级、安全限制和 CLI 见
[`Remake/docs/原生内容包与MapEditor工作流.md`](../Remake/docs/原生内容包与MapEditor工作流.md)。

刷新可直接运行的 `LocalBuild`：

```powershell
.\tools\Publish-LocalBuild.ps1
```
