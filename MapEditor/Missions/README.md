# VWF 关卡包工具

MOD 当前只发布原版 `m000`—`m011` 十二关，不再内置扩展关卡包。本目录保留
通用 schema、模板与构建器，供地图研究、格式验证以及 Remake 数据导入使用，
但模板产物不能自动视为可发布的原版引擎关卡。

清单结构由 `mission-package.schema.json` 描述，支持 JSON Schema 的编辑器
可以直接提示必填字段和 `composite` 专属字段。

进行格式实验时可复制 `_template` 中的示例文件，并遵循
[`doc/关卡制作与验证方法论.md`](../../doc/关卡制作与验证方法论.md)。
在尚未完成原版实机任务闭环前，不得仅凭 VWF 能载入就登记为 MOD 关卡。
