# 新关卡模板

1. 把本目录复制为新的 `mNNN` 目录；
2. 将三个 `*.example.json` 去掉 `.example`；
3. 填写真实源 VWF、源哈希、任务骨架、scene 索引、出生点和巡逻路线；
4. `redeploy` 模式不需要 `blueprint.json` 相关字段；
5. `composite` 模式必须填写蓝图、合成报告和预览资源字段；
6. 首次构建会故意因 `expected_output_sha256` 的零值失败；候选 VWF 和报告
   只留在 `-WorkDirectory`，不会覆盖发布文件。审阅候选和地图预览，完成
   运行测试后，才把实际哈希登记为新基线；
7. 将选择器、代理重定向、故事文档、截图和 CI 一并纳入同一提交。

禁止直接复制模板中的占位 scene 或哈希作为正式数据。完整流程与验收门槛
见 [`doc/关卡制作与验证方法论.md`](../../../doc/关卡制作与验证方法论.md)。
