# MapEditor 持续改进功能验收报告

## 1. 发布基线

- 框架：.NET 10 WPF，Release 构建 0 警告、0 错误；
- 入口：`MapEditor/LocalBuild/1937MapEditor.exe`；
- 产物清单：`MapEditor/LocalBuild/build-manifest.json`；
- 原版素材：1,037 项，全部具备放置元数据；
- 原生地图样本：`Mod/1937m000.vwf`—`1937m014.vwf`，共 15 张；
- 测试临时文件仅写入 `E:\1937`。

每次源码变化后运行：

```powershell
.\MapEditor\tools\Publish-LocalBuild.ps1
```

该脚本依次构建解决方案、对 15 张真实地图运行完整测试、发布应用并为每个
二进制生成长度和 SHA-256。只有三个阶段全部通过才刷新 `LocalBuild`。

## 2. 原生 VWF 安全写回

| 检查 | 结果 |
|---|---|
| 仅支持已知 VWF v5 | 通过 |
| 导入源只读、禁止覆盖源路径 | 通过 |
| 临时写入后重新解析 | 通过 |
| scene 数、记录长度、巡逻容量不变 | 通过 |
| 五层网格、世界/参考坐标、动态占用同步 | 通过 |
| 两套巡逻点同步 | 通过 |
| 二进制和语义 diff | 通过 |
| 已有输出 `.bak`、原子替换 | 通过 |
| m000—m014 无修改逐字节等价 | 通过 |
| 损坏/越界/增删 scene/容量变化拒绝 | 通过 |

编辑器有意不在原版变长记录中隐式插入 scene 或扩大巡逻数组。需要改变容量
的设计保存为 JSON 工程，再交由关卡包向导重新部署，避免生成“能写出但游戏
无法读取”的 VWF。

## 3. 质量分析和关卡包

问题面板包含 Error、Warning、Info，并能从问题定位到对象或格点：

- L1/L2/L3 接缝、跨区块建筑/桥/门/墙及素材 footprint；
- 连通分量、孤立区、窄通道和不可达任务点；
- 出生点视线、听觉、攻击及警报威胁；
- 巡逻路径相交、时间轴拥堵和狭路会车；
- 前景遮挡、角色排序和任务状态码映射。

可视化分析包括方向扇形视线及 L2 遮挡、听觉/攻击/警报边界、出生可达
热图、最短路径、AI 协同搜索，以及巡逻和玩家行动时间轴。所有近似数据都
显示来源，避免把编辑器估算误写为原引擎事实。

关卡包向导支持 redeploy 和 composite，生成：

- 隔离候选 VWF；
- 局部预览与质量报告；
- 确定性 SHA-256；
- 人工接受记录 `baseline-acceptance.json`；
- 选择器和代理共用的路由草案。

没有人工确认时，候选会停在发布边界，不覆盖源地图或 MOD 文件。

## 4. 编辑效率

自动测试覆盖：

- Ctrl+Z/Ctrl+Y 完整命令历史及合并；
- 多选、框选、对齐、分布、复制和批量属性；
- 矩形、画笔、区域填充；
- 巡逻点拖拽、插入、删除和容量检查；
- 名称、scene、资源、阵营筛选；
- 图层锁定、透明度、独显和组合预设；
- 原子自动保存、候选发现、恢复和丢弃；
- 视口裁剪及局部重绘。

当前大地图视觉基线为 m014（120×200、1,470 对象）：100% 缩放时只访问
1,643 个可见格和绘制 37 个对象，截图帧约 11.8 ms。该数值是编辑器
绘制统计，不等同于原游戏帧时间。

## 5. 资产、协作和任务格式

- `Assets/Original/asset-metadata.json` 覆盖 1,037 个素材的 footprint、
  移动/视线遮挡、门、推荐层级、类别和数值来源。
- `Generate-AssetMetadata.ps1` 可重复生成同一文件；CI 比较 SHA-256。
- 区域库复制地形、对象和路线时重新绑定对象 ID、scene 引用和占用。
- 语义 diff 区分对象移动、路线、图层和任务变化；三方合并报告冲突并
  保留用户选择。
- `IMapInterchangePlugin` 只加载 API 版本匹配的插件，重复 ID 会拒绝。
- 内置插件支持 `*.m37map`、普通 JSON 及正式
  `*.m1937mission.json`；复合后缀按最长匹配，避免被普通 JSON 插件误收。
- 三个发行 sidecar 的数据库对象 ID、区域、依赖、计数、可选、失败和
  超时字段均通过导入—导出 schema 往返。
- “高级任务”页可直接编辑 Sidecar ID、选择器关号、原版任务骨架，以及
  每个目标的依赖、可选/失败标志、失败原因、数据库对象、区域和期限；
  依赖列表会去空、去重并保持稳定顺序。
- 发布生成器一次生成 README、SVG 缩略图、故事、验证报告和
  `publication.json`。

## 6. UI 验证

启动时默认选中“鼠标箭头（仅查看）”，单纯浏览不会误放素材。常用流程固定
为“打开地图 → 选择素材 → 另存”，高级任务、协作和问题分析放在独立页。
界面采用高对比浅色工作区与深红命令栏，白字不再落在白色背景上。
