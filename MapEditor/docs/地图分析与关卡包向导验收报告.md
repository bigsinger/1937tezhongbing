# 地图分析、局部渲染与关卡包向导验收报告

> 当前状态（2026-07-29）：本文保留当时的研究结果；实验性扩展关包已删除，
> 当前 MapEditor 产品只把 m000—m011 作为随仓库发布的原生地图样本。

## 1. 交付范围

本轮把《MOD与MapEditor持续改进评估》中里程碑 C 的主要人工检查变成了
可复用实现：

- 当前视口格范围计算与局部重绘；
- 八方向 A*、出生点可达热图与目标最短路线；
- 敌军朝向扇形、L2 视线障碍截断、听觉/攻击/警报边界；
- 孤立区、窄通道、巡逻中间段、路线交叉和同步时间轴会车检查；
- `redeploy` / `composite` 关卡包 GUI 向导；
- 候选构建、报告、SHA-256 人工接受凭据和路由草案。

核心空间算法集中在 `MapEditor.Core/MapSpatialAnalysis.cs`。画布与问题面板
共用该实现，避免预览显示“可达”而质量检查报告“不可达”。

## 2. 数值来源

预览不是把估算冒充原版内部真值。界面和问题项分别显示以下来源：

| 预览值 | 默认值/规则 | 来源 |
|---|---:|---|
| 朝向 | 1 北、2 东北、3 东、4 东南、5 南、6 西南、7 西、8 西北 | 原版 SPR/VWF 方向语义恢复 |
| 视线 | 640 世界单位、90° 扇形 | 编辑器估算 |
| 视线遮挡 | VWF L2 非零格终止射线 | 原版地图数据 + 编辑器射线采样 |
| 近距听觉 | 128 世界单位 | 原版恢复值 |
| Mod 听觉 | AI 基值 128/160/192/224，再叠加难度 -32/0/32/64 | Mod 配置推演 |
| 攻击 | 256 世界单位 | 编辑器估算 |
| 警报 | AI 基值 640/720/800/960，再叠加难度 -160/0/160/320 | Mod 配置推演 |
| 路线时间轴 | 所有活物同速、同时从第一个点出发、往返移动 | 编辑器估算 |

绿色边界表示带遮挡视线，红色表示攻击，蓝色虚线表示听觉，橙色虚线表示
警报。只为当前选中的敌军绘制这些边界，避免对所有敌军逐帧射线计算。

## 3. 大地图性能

画布不再为每次滚动遍历整幅网格：

- 地表、L2—L5、网格按 `MapGridWindow` 裁剪；
- 对象在加载图片前先按扩展视口裁剪；
- 非所选巡逻路线先按路线包围盒裁剪；
- 动态运动标记只处理与当前视口相交的路线；
- 热图只绘制当前视口，连通距离场按起点缓存。

本地窗口直接渲染（不是桌面截图）的可复核数据：

```json
{
  "map_width": 120,
  "map_height": 200,
  "zoom": 1,
  "visible_cells": 1643,
  "drawn_objects": 96,
  "total_objects": 1470,
  "render_microseconds": 1649
}
```

`E:\1937\map-editor-tests\milestone-c-perf.json`。自动窗口放在屏幕外、
`ShowActivated=false`，不移动、锁定或回中系统鼠标。

## 4. 关卡包向导安全边界

向导流程如下：

1. 自动扫描 `MapEditor/Missions/mNNN` 与 `Mod/1937mNNN.vwf`，
   分配未使用的扩展 ID；
2. 要求源 VWF 位于 Git 项目内，避免生成他人无法复现的绝对路径；
3. 从源文件真实 scene 中选择玩家、敌军、目标、接头和出口；
4. 写入新的 mission 目录，不覆盖既有 mission 或源 VWF；
5. `composite` 先在 `E:\1937\mission-wizard\mNNN` 合成预检，
   生成局部预览，并把合成结果哈希写入任务定义；
6. 统一调用 `Build-MissionPackage.ps1` 生成候选 VWF 和报告；
7. 清单初始哈希固定为 64 个 `0`，因此首次构建不能发布；
8. 用户阅读预览和 `validation.md` 后必须显式勾选人工确认；
9. 再次核对工作目录候选哈希，写入清单和
   `baseline-acceptance.json`，随后确定性构建才可发布；
10. `mission-route.draft.json` 只作为选择器/代理路由草案，不自动修改
    SDK 权威路由表。

这保证“一键生成”不会变成“一键接受未知二进制”。

## 5. 自动测试

执行：

```powershell
dotnet build .\MapEditor\MapEditor.slnx -c Release
$env:M1937_TEST_VWF_DIRECTORY = (Resolve-Path .\Mod).Path
dotnet run --project .\MapEditor\MapEditor.Tests\MapEditor.Tests.csproj `
  -c Release
```

2026-07-27 本地结果：

- Release 构建：0 warning、0 error；
- 视口裁剪、可达热图、方向与遮挡扇区：通过；
- m000—m014 无修改原生 VWF 字节等价：通过；
- 对象/参考坐标/动态占用与巡逻同步：通过；
- 损坏、越界、scene 数和巡逻容量变化拒绝：通过；
- redeploy/composite 草案、ID 分配、候选 SHA-256 和二次接受拒绝：通过；
- 100% 缩放窗口自渲染：1,643 / 24,000 格，96 / 1,470 对象，
  约 1.65 ms（单次本机采样，不代表所有设备的帧时基线）。

性能数据是开发机单次窗口渲染诊断；正式 MOD 的 10 分钟 P95/P99 基线仍由
独立游戏遥测里程碑负责。
