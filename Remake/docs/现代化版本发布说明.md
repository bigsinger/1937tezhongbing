# Remake 现代化版本发布说明

发布日期：2026-08-05

状态：现代化改造与本地全量验收完成；便携产物由同一提交构建。

## 面向玩家的变化

- 启动后直接进入十二关选择，不再播放旧 logo 和历史 CG；Copy 便携包也不再
  携带两段启动影片。
- 支持窗口、桌面全屏、无边框最大化和 `Alt+Enter`；可以设置 VSync、帧率
  上限、窗口尺寸、UI 比例和文字比例。
- 经典操作完整保留，并新增现代 RTS 方案、控制组、相机书签、双击同类选择、
  可调镜头和不中断桌面鼠标的边缘卷屏。
- 攻击前可看到武器、距离、射程、命中率和声音影响；不可达、遮挡、距离、弹药
  及未命中原因会直接反馈。
- 经典/现代规则与剧情/普通/困难/自定义难度互相独立；自定义难度可分别设置
  敌军命中、反应、感知、搜索、警报和增援。
- 新增高对比度、大光标、视野纹理、完整字幕、减少闪光、减少镜头运动、失焦
  暂停、弱化暴力和教育模式。
- 十二关新增历史背景、目标语境、史实与艺术加工说明、历史档案和任务复盘统计。
- 存档升级到 schema 2，加入滚动检查点、内容身份、损坏检测、备份回退和旧版
  迁移；十槽列表读取更快。

## 性能与可靠性

- 敌军感知错峰执行，世界查询使用空间索引，投射物和爆炸只访问邻近单元。
- 寻路有单帧预算、请求队列、静态失败复用和多人巡逻路径共享。
- 常用 UI、字体、图标和音效预热，首次操作受 25 ms 门禁约束。
- 关卡文件读取和解码可后台执行，主线程显示阶段进度并安全创建节点。
- 内容包带版本化 manifest 和 SHA-256 校验；损坏、缺失或越界文件会被拒绝。
- 可导出不含存档正文、私人路径和自定义按键的诊断包。

## 已知边界

- Windows 10 / GTX 1050 Ti / 1080p 是本地性能参考机；Windows 11、低端核显、
  物理 4K 和真实多显示器环境仍需要社区真机补充数据。
- 中文和英文覆盖本轮新增的产品界面；原始素材内嵌文字和历史对白不会自动翻译。
- 教育说明用于游戏语境补充，不替代正式教材或史料研究。
- 代码签名为可选发布步骤；没有项目证书时仍会提供 SHA-256 校验值，但 Windows
  可能显示未知发布者提示。

## 构建与校验

```powershell
.\tools\Build-Playable.ps1 `
  -GodotExecutable D:\Godot\Godot_v4.7.1-stable_win64_console.exe `
  -AssetMode Copy -CreateArchive $true
```

输出：

```text
Remake/LocalBuild/1937Remake/
Remake/LocalBuild/1937Remake-portable.zip
Remake/LocalBuild/1937Remake-portable.zip.sha256
```

目录内 `build-info.json` 记录提交、Godot、构建类型和内容身份；
`SHA256SUMS.txt` 校验 EXE、PCK、构建信息和内容 manifest。详细结果见
[现代化改造验收报告](现代化改造验收报告.md)。
