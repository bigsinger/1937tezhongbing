## 1. 边界与基线

- 行为基线为 `daae74b`，实施起点为 `89b5eb9`。
- 版本化度量位于
  `validation/baselines/remake/modernization-round2-baseline-v1.json`。
- 本轮只修改 Remake 及其必要的 MapEditor 对接面；Patch、Mod 运行时代码不在
  实施范围内。
- 用户现有 Mod 存档、SI、配置和遥测保持原样，不暂存、不覆盖。
- 没有生成或上传绿色 ZIP、EXE、PCK、完整游戏资源或 QA 临时输出。
- 自动输入只发送到 Godot 自己的目标视口；门禁明确检查全局鼠标移动、捕获、
  裁剪和锁定调用为零。

最终仓库守卫识别到 12 个既有 Mod 用户数据变更，并全部保持未暂存；源码/文档
范围的 3,144 个已跟踪或待提交文件通过原始资产与发行物签名检查。

## 3. 关键实现落点

### 3.1 模拟、命令和回放

- `simulation_clock.gd`、`simulation_coordinator.gd`、`simulation_system.gd` 和
  `scheduled_game_command.gd` 建立唯一固定玩法时钟。
- `command_replay.gd`、`command_replay_runner.gd` 和 `replay_state_probe.gd`
  记录规范化命令，不记录桌面鼠标轨迹。
- 存档 schema 4 保存模拟 tick、命令序列、战术队列、预约、AI 黑板和内容身份；
  schema 0—3 通过单向迁移补齐安全默认值，未来 schema 保持拒绝读取。

### 3.2 运行时结构与性能

- Main 继续作为组合根和兼容门面，具体职责已迁入控制器和服务。
- 静态 scenery 队列预合成为地形图像；逐行精灵把相邻且基线一致的 32 像素列
  合并，保持像素结果不变并降低对象/Draw Call 压力。
- 音频、空闲表现、敌人感知/决策/视线和预约使用不同固定更新频率；所有会影响
  胜负的状态仍由 60 Hz 模拟 tick 决定。
- `RuntimePerformanceMonitor` 记录实际呈现帧间隔、Main CPU、物理 CPU 和系统
  分项；不再把 Godot 保持型监控值误当作逐帧采样。

### 3.3 产品 UI、潜行和战术计划

- 主要菜单和 HUD 已场景化；底部 HUD、字幕、地图、背包、暂停/失败/存档/设置
  共享安全区和世界输入屏蔽。
- 中英文可在运行时切换，产品可见字符串必须存在于两份词典，少量技术诊断文字
  只能通过版本化白名单保留。
- 潜行反馈以状态变化驱动，视线边界、怀疑、搜索和最近证据不会每帧重建。
- 现代规则可暂停模拟并排列多步命令；镜头和 UI 继续响应，经典规则不自动
  开启该能力。

### 3.4 AI 与移动

- `MovementReservationService` 在提交移动前预约目标格，并使用稳定 scene 顺序、
  等待年龄和有界恢复解决门口、树林和窄路冲突。
- `AiEvidenceBlackboard` 只接收视觉、听觉、尸体和通信事件；丢失视线后不保存
  玩家实时引用。
- 搜索队员获得不同扇区，通信有距离/延迟约束；警戒超时后释放任务并返回原岗位
  或巡逻路线。

### 3.5 原生内容包

- 格式与安全策略实现于 `tools/ResourceFormats/M1937Pack*.cs`，CLI 位于
  `tools/ResourceTool`。
- Godot 运行时由 `m1937_pack_loader.gd` 和 `native_content_runtime.gd` 负责发现、
  校验、装配和内容身份隔离。
- MapEditor 使用同一库导出，合成示例位于 `examples/synthetic-pack-source`；测试
  从零构建、验证、加载并完成任务，不需要原版数据。
- 路径穿越、大小写碰撞、漏报/多报、哈希错误、脚本/可执行载荷、超限资源、缺失
  依赖和冲突包均会在接触正式存档前安全拒绝。

## 5. 严格性能结果

验证环境：Windows 10、Godot 4.7.1 Compatibility、NVIDIA GeForce GTX 1050 Ti、
1920×1080 窗口、60 FPS、VSync 关闭、十二关两轮、600 秒。

最终确认运行共取得 33,108 个呈现帧，P95 为 **18.398 ms**，P99 为
**20.304 ms**。全部 2,466 次输入只发送给游戏视口；第二轮静态内存净增长
2.567 MiB。最慢冷加载为 m004 的 5,888.0 ms，最慢热加载为 m004 的
2,668.6 ms；十二个热加载均命中隔离的静态导航连通分量缓存。

## 6. 分层门禁

- `Invoke-RemakeFastGate.ps1`：无原始资源的格式、脚本、逻辑和合成产品测试。
- `Invoke-RemakeContentGate.ps1`：真实十二关内容、回放、任务、导航、UI 和产品旅程。
- `Invoke-RemakeReleaseGate.ps1`：完整 Verify、严格性能及 30 分钟稳定性。
- `Invoke-RemakeGate.ps1 -Tier <Quick|Content|Release> -Resume`：统一入口和可恢复
  执行状态；每个步骤使用输入摘要识别过期结果。

CI 只运行可在无商业资源环境成立的源码、schema、合成内容和安全门禁；本地内容
与发布门禁使用忽略目录中的合法资源，结果不会进入 Git。

## 7. 最终稳定性与发布门禁

Release 在参考机器上完成 **31.61 分钟**无交互稳定性运行，连续执行三轮十二关、
36 次物理存档和 36 次读取。结果如下：

- P95 19.559 ms，P99 24.618 ms；
- 最慢冷加载 5,854.347 ms，低于 6,000 ms 门槛；
- 最慢热加载 2,274.202 ms，低于 3,500 ms 门槛；
- 第二遍静态内存净增长 4.786 MiB，低于 8 MiB 门槛；
- 每关三次访问均有真实敌军移动，第二、三轮全部命中隔离导航缓存；
- 36 次存档/读取、无崩溃、无脚本错误、无全局鼠标控制；
- Release 汇总 33/33 步通过。

长稳门禁使用显式的“模拟专用静态视觉策略”：仍运行任务、AI、动态角色表现、
导航、门、拾取、输入和存读档，但在 64×64 headless 后端不反复解码 21—66 MiB
地形或创建不可见的纯装饰 CanvasItem。完整静态世界渲染由 1920×1080 十分钟
真实窗口性能门禁和双分辨率产品 UI 门禁独立覆盖。该策略只由测试参数启用，
不持久化，也不会进入玩家会话。

- 已验证硬件只代表上述 Windows 10 / GTX 1050 Ti 环境。
