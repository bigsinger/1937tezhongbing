验收日期：2026-08-09

本报告对应[《Remake 现代化第二轮持续改进实施方案》](现代化第二轮持续改进实施方案.md)。

绿色 ZIP、EXE、PCK、原版素材、用户存档、遥测或本地 QA 产物，也没有捕获、
裁剪、移动或锁定系统鼠标。

## 3. 分层门禁结果

- Quick：仓库源码、schema、合成 fixture、.NET/Godot 逻辑与产品壳测试通过；
- Content：31 个真实内容步骤通过，覆盖十二关输入、任务、导航、物品、UI、
  MapEditor 内容包和产品旅程；
- Release：33/33 步通过，包括完整 Verify、正式性能证据及 31.61 分钟稳定性；
- Release 的 `-Resume` 只复用输入摘要完全相同且报告完整的成功步骤；本轮受影响的
  测试与最终 30 分钟稳定性均重新执行，源码或参数变化会使旧步骤自动失效。

这些门禁只向 Godot 目标视口发送合成输入。自动测试不会操作桌面鼠标，也不会
自动尝试整关真人通关。

## 4. 十二关真实窗口性能

环境为 1920×1080 窗口、60 FPS、VSync 关闭、Compatibility renderer、十二关
两轮、600 秒。最终确认运行取得 33,108 个呈现帧：

- P95 **18.398 ms**，低于 18.5 ms 总体门槛；
- P99 **20.304 ms**，低于 25 ms 门槛；
- 每关 P95 均低于 19.5 ms，每关两轮均有真实敌军移动；
- 第二轮静态内存净增长 **2.567 MiB**，低于 8 MiB 门槛；
- 最慢冷/热加载分别为 **5,888.0/2,668.6 ms**，所有热加载命中静态导航缓存；
- 2,466 次输入均为目标视口输入，`global_pointer_control=false`。

运行保留了两次宿主调度抢占的原始墙钟数据：m008 为 198.188 ms，m011 为
81.373 ms。二者同帧 Main、物理、导航工作量和模拟 tick 数不足以解释停顿，已由
分类器标记为宿主抢占；十二关无法解释的产品长帧仍为 **0**。提交的版本基线另
保存了一次无宿主抢占的干净运行：33,130 帧、P95 18.193 ms、P99 20.236 ms、
零个 >50 ms 帧，见
[`campaign-performance-1920x1080-v1.json`](../validation/baselines/remake/campaign-performance-1920x1080-v1.json)。

## 5. 30 分钟稳定性

最终 Release 稳定性运行持续 **31.61 分钟**，循环十二关 3 轮：

- P95 **19.559 ms**，P99 **24.618 ms**；
- 最慢冷/热加载 **5,854.347/2,274.202 ms**；
- 第二遍静态内存净增长 **4.786 MiB**；
- 每关三次访问均有 AI 实际移动，后两轮导航缓存全部命中；
- 36 次存档、36 次读取全部成功；
- 无崩溃、无脚本错误、无全局鼠标控制。

长稳门禁在 64×64 headless 后端显式启用“模拟专用静态视觉策略”：任务、AI、
动态角色、导航、门、拾取、输入和存读档保持完整，但不反复解码大地形或创建不可见
的纯装饰 CanvasItem。该参数不持久化，在正常/窗口运行中默认为关闭。静态世界
渲染由上一节的真实窗口门禁与 1024×768、1920×1080 产品 UI 门禁独立约束。
提交基线见
[`stability-soak-30-minute-v1.json`](../validation/baselines/remake/stability-soak-30-minute-v1.json)。

## 6. 实际验证环境与边界

已验证参考机：

- Windows 10 专业版 10.0.19045；
- Intel Core i5-7500，16 GiB 内存；
- NVIDIA GeForce GTX 1050 Ti；
- Godot 4.7.1 stable official，Compatibility renderer。

以下内容不冒充已完成的真机证据：Windows 11、低端核显、物理 4K、多显示器/
不同 DPI 和更多输入设备仍需社区硬件矩阵；自动产品旅程证明状态、输入和任务闭环，
但不等同于稳定 MOD 与 Remake 两边的十二关真人非作弊完整通关录像。这些是外部
兼容性和体验验证边界，不是第二轮批准范围中的遗留占位实现。

## 7. 最终结论

《Remake 现代化第二轮持续改进实施方案》的全部批准工作包和完成定义已经满足，
本轮目标可以关闭。后续若继续迭代，应以本报告、两份版本化性能基线和三级门禁为
回归基准；修改玩法后先跑 Quick，涉及真实关卡时跑 Content，发布候选才跑 Release。
