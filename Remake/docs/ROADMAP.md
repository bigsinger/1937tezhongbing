# 开发路线图

完整复刻的实施顺序、证据规则、逐关验收与发布硬门禁见
[稳定 MOD 完全复刻开发实施方案](MOD完全复刻开发实施方案.md)。本路线图
保留子系统历史进度；若二者的“完成”口径不同，以 parity contract 和实施
方案的端到端验收为准。

本路线图区分四种状态：格式可解析、资产可转换、数据可在 Godot 中运行、任务可完整游玩。前面三项不能替代最后一项。

## 性能与兼容性目标

- 1920×1080、60 FPS；
- P95 帧时间不超过 20 ms，P99 不超过 25 ms；
- 正常游玩期间不出现超过 50 ms 的同步资源加载尖峰；
- 十分钟自动回放无状态漂移、无持续内存增长；
- 默认 Godot Compatibility renderer，可在 Windows 10/11 和常见旧集成显卡运行。

当前参考基线来自 Windows 10 19045、GTX 1050 Ti、Godot 4.7.1

16.667 ms、P95 18.167 ms、P99 20.936 ms、最大 47.976 ms，没有帧超过
50 ms。最密集的 m004 为 P95 18.941 ms、P99 22.824 ms；第二轮结束仅比
第一轮增加 1,063,804 字节静态内存，24 次载入全部低于 3.4 秒。精简证据保存在
`validation/baselines/remake/campaign-performance-1920x1080-v1.json`，原始
本地日志留在被忽略的 `LocalAssets/qa/`。这仍不是所有硬件的发布承诺；
