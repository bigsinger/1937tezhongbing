这是可以直接运行的原版增强发行目录，不再依赖仓库外的
`E:\1937\1937tzb_1229`。GitHub 用户克隆仓库时需要启用 Git LFS：

普通玩家也可从
[最终归档 Release](https://github.com/bigsinger/1937tezhongbing/releases/tag/archive-2026.08.10)
下载 `1937-Mod-portable.zip`，无需安装 Git LFS。

```powershell
git lfs install

cd .\1937tezhongbing\Mod

```

先恢复原生 1024×768 安全窗口配置，可用于修复错误显示设置。

## 设置与持久化

启动中心把设置保存到原版自带的 `rungame.ini` `[mod]`，包括：

- 难度与敌军 AI 等级；
- 敌军听觉、增援警报半径（可自动计算或手工覆盖）；
- 原版边缘卷屏兼容（不启用实验性的回中或第二套平滑层）；
- 输入法屏蔽与高精度计时；
- 推荐的原生 1024×768 窗口、无边框最大窗口、保持比例全屏和铺满全屏；
- 当前桌面分辨率、渲染后端和上次所选关卡。

“高级增强设置”还提供：

- 结构化诊断和分通道性能遥测；
- 可关闭的按键别名，冲突会在保存前拒绝，F1/M 原始语义始终保留；
- 可选任务 sidecar 和 x64 原生插件。两项默认关闭，加载失败时完整回退
  原版任务逻辑；`Tools/MissionSidecar/build-manifest.json` 记录 API、
  架构和每个运行文件的 SHA-256。

默认配置为 Direct3D 9、60 游戏逻辑帧、VSync。游戏内部保持原版
1024×768 UI 画布，再由 cnc-ddraw 输出到桌面分辨率。这是因为原版
底部工具栏、F1 帮助和 M 小地图只提供了三套固定分辨率界面资源；直接
扩大引擎逻辑画布会让这些功能消失。默认推荐“原生窗口 1024×768”：
画面与原版逻辑坐标 1:1，不拉伸、不锁系统鼠标，也不记忆异常窗口尺寸。
无边框最大窗口和真正全屏仍作为兼容备用。

发布门禁禁止移动、裁剪、捕获或回中系统光标。菜单和第一关场景又分别
完成 60 秒只读裁剪监测，共 1,914 个样本，限制样本为 0；测试仅向隔离
窗口的进程内 DirectInput 队列发送输入。

兼容层不会提前移除键盘、鼠标消息，F1、M 和其他原版按键仍由游戏主
循环按原顺序处理。消息泵采用 8 ms 节流，cnc-ddraw 使用 BltFast
限帧点，减少输入轮询与渲染限帧互相抢占造成的偶发卡顿。自动开始关卡
通过菜单命令钩子完成，不再注入测试鼠标位移。缩放模式继续使用
cnc-ddraw 的 DirectInput 坐标转换；原生窗口不需要灵敏度缩放。
菜单、小、中、大地图四组 10 分钟正式基线共 38,739 个样本，P99 为
9.414—12.837ms，未响应、超过 50ms 卡顿和遥测丢失均为 0。

## 正式关卡

程序引用和 VWF 格式审计均确认正式任务是 `m000`—`m011`，共 12 关。
以前混入目录的 `m012`—`m015` 是 2004 年其他软件 ZIP/CDXA 数据，
不属于本游戏且已从发行目录移除。

MOD 只保留这 12 个已验证原版任务，不再发布第 13—15 关或相应任务
sidecar。地图实验工具仍位于 [`MapEditor`](../MapEditor/)，但其实验产物
不会自动进入 MOD。

详细说明见 [使用说明.txt](使用说明.txt) 和仓库
[Patch/docs](../Patch/docs/)。本轮全部持续改进及验收证据见
[实施报告](../doc/MOD与MapEditor持续改进实施报告.md)。
