# 《1937特种兵：敌后武工队》Win10/Win11 兼容补丁

> 这是仓库中的原版兼容补丁子项目。复刻工程见 [Remake](../Remake/)。

本项目整理并发布《1937特种兵：敌后武工队》绿色版在 Windows 10/11 上的兼容性修复方案。

项目只发布兼容层、补丁包、源码、测试工具和文档，不包含原游戏主程序、关卡、GFL/VWF/SVT/SAV 资源或商业发行内容。使用者需要自行准备合法的绿色版游戏目录。

## 快速使用

下载 [完整补丁包](release/1937特种兵-Win10-Win11兼容补丁-v1.4.1-20260727.zip)，
解压后运行 `Install-Patch.cmd`，输入 `M1937.exe` 所在目录即可。安装器会
校验主程序 SHA-256，并在覆盖前建立恢复备份。

v1.4.1 提供现代启动中心。右键运行游戏目录中的 `选择关卡.ps1`，或双击
`启动现代增强版.cmd`，可选择 12 个原版任务及目录中已安装的 3 个扩展
任务。选择器只给本次
进程传入关卡号；补丁经原机器码校验后在内存中替换“新游戏”入口的关卡
立即数，不改原版 EXE、资源或存档。普通启动仍从第一关开始。

安装后建议运行游戏目录中的 `启动现代增强版.cmd`，在启动中心选择
“原生窗口 1024×768（推荐、最稳定）”。无边框和真正全屏仍保留为
兼容备用，但不再作为默认值。

## 最终修复内容

- cnc-ddraw 7.1.0.0 将旧 DirectDraw 路径转换到 Direct3D 9；
- 游戏逻辑 Tick 60、VSync 和 BltFast 限速，修复桌面合成丢帧与消息泵争用造成的微卡；
- 自研 DirectInput 代理以限频、限量消息泵解决“未响应”，且不抢占 F1/M 等热键；
- 自动开始关卡不再注入合成鼠标；默认原生 1024×768 窗口不拉伸、
  不锁系统鼠标，cnc-ddraw 输入钩子在缩放模式下保持可用；
- 对指定版本进行安全的内存补丁，消除资源库误报并跳过两个问题启动影片；
- 提供独立的关卡选择器，按次启动任意原版关卡；若游戏目录包含本项目的
  `1937m012.vwf` / `1937m013.vwf` / `1937m014.vwf`，还会分别显示
  扩展关“余烬行动”“锄奸行动”“破晓密令”，普通启动语义不变；
- 保留原版 1024×768 完整 UI，再缩放到当前桌面分辨率，修复底栏、F1 帮助和 M 小地图。
- 结构化诊断、分通道性能遥测、可关闭按键别名和 15 关十阶段自动回归；
- 有界最后目击点 AI，以及默认关闭、失败回退的任务 sidecar/原生插件。
- 仓库的完整 `Mod` 为 15 关保留原版任务简报画面和点击/Enter 继续流程，
  不创建额外窗口；文字由 `关卡名称.json` 绘制为 640×480
  RGB565/IBLOCK 并写回 GFL；
- “破晓密令”同步渲染与点击换算相机，并采用拓扑安全地表合成保护原任务
  的硬编码路径；回归要求玩家产生真实位移、目标格和方向帧变化，而不再
  只判断点击消息是否送达。

`Patch/release` 的轻量兼容补丁不重复打包原游戏 GFL；需要文字简报和三张
扩展地图时请直接使用仓库 `Mod` 目录。

## 目录说明

```text
docs/          技术说明、使用帮助和验证报告
src/           自研 DirectInput 兼容层源码工程
tools/         MOD 构建、任务 Sidecar 工程和发布脚本
release/       可分发 ZIP、校验文件和发布说明
analysis/      帧时间工具及关键原始测试结果
third_party/   cnc-ddraw 版本、许可证和官方源码归档
```

兼容层引用仓库根目录的 [`SDK/`](../SDK/)；已分析地址、原版结构和安全
写补丁原语集中在 SDK 中维护，避免工具与运行补丁各自复制裸地址。
