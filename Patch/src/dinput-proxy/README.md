# 1937 DirectInput 兼容与增强层

这是 32 位 `dinput.dll` 代理源码，只对已验证的
`M1937.exe`（SHA-256 `F4DD1131...B64DA3F3`）应用内存补丁。

主要功能：

- 启动时把 Windows 当前版本的 32 位系统 DirectInput 复制为
  `dinput_system_<进程号>.dll` 后加载，避免同名代理递归加载、栈溢出，
  以及快速重启时与上一进程尚未卸载的映像冲突；下次启动会清理未被占用的
  旧副本。这类文件是本机运行时缓存，不属于可分发产品；
- 以 8 ms 节流、仅处理重绘/计时/关闭消息，消除旧输入循环造成的
  “未响应”，同时不提前吞掉 F1、M 等键盘消息；
- 屏蔽游戏窗口 IME，启用 DPI 感知和 1 ms 高精度计时；
- 修复错误的资源库警告并跳过两个有问题的启动影片；
- 按 `SDK/mission-routes.json` 生成的只读表处理全部 1—12 关；
- 关卡路由先验证文件和全部签名字节，再成组写入；任一写入失败会回滚
  已完成的重定向并保留原版行为；
- 关卡编号只在原菜单“开始游戏”路径生效，不伪造存档；
- 可选 `SystemCursorMapping=1` 将客户区内的 Windows 光标只读映射为
  原版 DirectInput 相对位移；不锁定、不回中、不移动系统光标；
- 保留原版边缘卷屏；旧的自制平滑卷屏配置不再启用；
- 按难度和 AI 等级调整听觉/警报，并在原版警报入口实现有界最后目击点
  AI：反应延迟、最近 1—4 名增援、前向截击、2—4 点搜索、重获目标和
  超时交回原版 AI；警报后不持续读取视线外玩家坐标；
- 可关闭的按键别名只增加目标键状态，不吞掉源键，F1/M 原始语义保留；
- 默认保留 1024×768 原版逻辑界面，由 cnc-ddraw 缩放到现代桌面
  分辨率，确保底部工具栏、F1 帮助和 M 小地图完整；
- 旧的实验性扩展逻辑视口仅能通过
  `M1937_UNSAFE_EXPANDED_VIEWPORT=1` 显式启用，不作为发行设置；
- 为旧引擎可选 UI 素材增加空指针防护。
- 默认把 EXE 兼容性、签名拒绝、已启用功能和回滚结果写入游戏目录
  `M1937Mod.log`（JSON Lines）；日志不记录桌面截图、按键、鼠标坐标或
  用户文件路径，可用 `[mod] Diagnostics=0` 关闭。
- 可选 `M1937Telemetry.jsonl` 区分消息泵、DirectInput、回放延迟、AI、
  磁盘首载和镜头变化。快照进入固定容量队列，由低优先级后台线程写盘；
  DirectInput/消息泵路径不执行文件 I/O，队列丢弃数也会写入下一条快照。
- 自动验证通过游戏窗口私有消息进入本进程 DirectInput 队列，不调用
  全局鼠标、系统输入或前台焦点 API；源码门禁还拒绝光标裁剪、捕获/
  释放调用，运行回归用只读 `GetClipCursor` 要求菜单和场景限制样本为 0。

已知 EXE 地址、VWF 结构和安全内存写入统一来自
[`../../../SDK/`](../../../SDK/)，代理不再维护另一份裸地址清单。

配置来自游戏目录的 `rungame.ini` `[mod]`。构建：

```bat
build.cmd
```

脚本自动定位 Visual Studio C++ x86 工具链，输出
`build\dinput.dll`。目标必须是 x86，因为游戏是 PE32。
