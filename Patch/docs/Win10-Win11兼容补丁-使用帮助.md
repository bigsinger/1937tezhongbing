# 《1937特种兵：敌后武工队》Win10/Win11 兼容补丁 v1.4.2

发布日期：2026-07-27

## 这个补丁解决什么问题

本补丁用于让《1937特种兵：敌后武工队》绿色版在 Windows 10/11 上流畅、稳定运行，主要解决：

- 启动时报 `DirectDraw Error DDERR_UNSUPPORTED`；
- 弹出 `Can't Load Game Files Library!` 误报；
- 片头、菜单、任务简报或点击“开始游戏”后长时间“未响应”；
- 进入关卡后帧率低、旧循环占用 CPU 或偶发微卡；
- 全屏不能正确采用当前 Windows 桌面分辨率。
- 从启动中心自动开始任务时鼠标自行漂移或灵敏度异常。
- 无边框/全屏拉伸时关闭坐标映射造成鼠标完全无法操作。

最终方案使用官方 cnc-ddraw 7.1.0.0 将 DirectDraw 转为 Direct3D 9，并附加本游戏专用 DirectInput 兼容层。原版 `M1937.exe` 不会被改写。

## 适用版本

安装器只接受经过完整测试的绿色版：

```text
文件：M1937.exe
SHA-256：F4DD1131DF6C993C01EA011F9439BC725E6DC6491B5FBBA47724D7D5B64DA3F3
```

其他版本的程序布局和机器码可能不同，安装器会拒绝安装，不能强行混用。

本压缩包不含原游戏程序、关卡、音视频或资源文件。

## 推荐安装方法

1. 解压本压缩包到任意目录；
2. 双击 `Install-Patch.cmd`；
3. 按提示输入游戏目录，例如：

   ```text
   E:\1937\1937tzb_1229
   ```

4. 安装器会校验 `M1937.exe`，备份目标目录中可能被覆盖的旧兼容文件，然后复制补丁；
5. 安装完成后，双击游戏目录中的 `启动游戏-窗口模式.cmd`。这个入口
   每次都会先恢复经过菜单和第一关实测的 1024×768 稳定窗口配置。

也可以在命令行指定游戏目录：

```bat
Install-Patch.cmd "E:\1937\1937tzb_1229"
```

## 现代启动中心与 12 个原版关卡

使用仓库的完整 `Mod` 时，游戏目录会出现：

- `选择关卡.ps1`：现代启动中心；
- `启动现代增强版.cmd`：可双击的启动入口；
- `关卡名称.json`：12 条数据化路由和标题；
- `Tools\MissionSidecar`：默认关闭的可选任务主机。

右键运行 `选择关卡.ps1`，或双击 `启动现代增强版.cmd`。选择第 1—12
关中的任意一关。点击
“进入原版菜单（所选任务）”后，在原版菜单点击“新游戏”。此时游戏进程
内仍显示原来的任务简报画面；区别仅是原图片内容已经替换为该关的文字剧情
和三项目标。像原版一样单击鼠标或按 Enter 继续，不会出现第二个弹窗，也
不会模拟点击或移动系统鼠标。启动中心还可以配置并持久化难度、AI、显示、
渲染、输入法屏蔽和计时选项。

全部文案位于 UTF-8 的 `关卡名称.json`。仓库开发者修改 `title`、
`briefing` 和 `objectives` 后运行：

```powershell
.\Patch\tools\Update-TextBriefings.ps1 `
  -RepositoryRoot (Get-Location)
```

工具会在 `E:\1937` 生成临时文件和 12 张预览图，校验成功后再成对替换
`Mod\1937Resources.GFL` 与 `Mod\InterMedia.GFL`。玩家下载的成品已经
包含生成结果，正常游玩不需要执行该命令。

`Patch/release` 中约 3 MiB 的轻量兼容补丁有意不携带原游戏 GFL 和 VWF；
它只修复已有原版安装。完整 12 关 MOD 由 Git LFS 管理。

“高级增强设置”提供结构化诊断、分通道遥测、任务 sidecar、原生插件和
按键别名。Sidecar/插件默认关闭，需要 .NET 10 Desktop Runtime；关闭时
游戏不依赖 .NET。按键别名只增加目标键，不吞掉源键，F1/M 保持原义。
压缩包的 `source/Patch/tools/MissionSidecar` 和 `source/SDK` 同时提供
可复编译主机、版本化插件 ABI、示例插件及 schema，方便在相同接口版本
上扩展。

这个功能不会生成伪存档，也不会改写 `M1937.exe`。选择器通过进程环境
变量传入 1—12；`dinput.dll` 先校验目标 PE 和“新游戏”入口的原始
字节，再只在内存中替换关卡立即数。无效值和其他 EXE 版本都不会套用。

命令行也可以预置关卡；为兼容旧快捷方式保留的 `-StartImmediately`
现在同样先进入原版菜单：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\选择关卡.ps1 -Level 12 -StartImmediately
```

## 手动安装

如果不使用安装器，把 `payload` 文件夹中的所有文件复制到 `M1937.exe` 所在目录，允许合并文件夹即可。

不要把 `payload` 文件夹本身套进游戏目录；需要复制的是它里面的内容。

如果此前安装过旧版，建议使用 v1.4.2 安装器而不是手动覆盖。安装器会按路径和 SHA-256 清理旧版文件；修改过或未知的文件不会删除，并会显示警告。

## 启动和全屏

- 推荐入口：`启动现代增强版.cmd` 或 `选择关卡.ps1`；
- 推荐显示模式：“稳定窗口 1024×768（推荐、已验证）”；
- `Alt+Enter`：在窗口和全屏之间切换；
- 全屏输出会读取当前显示器分辨率，本机验证为 1920×1080；
- 再按一次 `Alt+Enter` 会恢复原窗口尺寸；
- `Ctrl+Tab`：临时释放被游戏锁定的鼠标；
- `兼容补丁设置.cmd`：打开 cnc-ddraw 设置程序。

“稳定窗口 1024×768”是 v1.4.2 的默认推荐模式。专用 `dinput.dll`
读取系统光标在游戏客户区中的位置，并换算为原版 1024×768 DirectInput
相对位移；它不会调用 `SetCursorPos`、`ClipCursor`，不会锁定、回中或
主动移动 Windows 光标。cnc-ddraw 的第二套鼠标缩放与约束在此模式下
关闭，避免两套映射互相影响。

无边框、全屏缩放和全屏铺满暂时保留为实验选项。“全屏缩放”保留原版
4:3 比例；“全屏铺满”同样保留原版 1024×768 游戏和 UI 画布，再将最终
画面铺满桌面，不留黑边。v1.3.1
停用了不安全的内部画布扩展，因为原版没有对应宽屏尺寸的底栏、帮助和
小地图资源，会造成底部工具栏消失、F1 黑屏以及 M 键失效。

## 卸载与恢复

双击压缩包中的 `Uninstall-Patch.cmd`，输入同一个游戏目录。脚本会移除本补丁安装的文件，并恢复首次安装前备份的同名文件。

首次安装备份保存在：

```text
游戏目录\.1937-compat-backup-before-v1.1.0
```

这个目录名为兼容 v1.1.0 的既有安装而保持不变；后续版本（包括
v1.4.2）会继续复用首次安装前的原始备份，避免升级时把旧补丁文件误当成
原文件。安装和卸载会清理路径与 SHA-256 都匹配 v1.1.0 发布物的旧
Shader；任何修改过的文件都会保留并警告。

卸载脚本会保留这个备份目录，避免误删恢复材料。

命令行使用方式：

```bat
Uninstall-Patch.cmd "E:\1937\1937tzb_1229"
```

## 常见问题

### 1. 为什么跳过了开场动画？

两个启动 `.svt` 影片的旧播放循环会在现代 Windows 上长时间不处理窗口消息，是启动假死的主要来源。补丁只跳过两个启动影片，不影响任务和关卡视频。

### 2. VSync 会不会影响操作？

VSync 理论上会增加最多约一帧输入等待，但本游戏属于即时战术游戏。实测开启后桌面合成丢帧率从 18.81% 降到 0%，平滑度收益更明显。

### 3. 想让宽屏显示更多地图怎么办？

原版内部只提供 640、800 和 1024 三套 UI 资源，直接扩大逻辑画布会破坏
工具栏、F1 帮助和 M 小地图，因此 v1.3.1 起不再默认提供此模式。可选择
“全屏铺满”充分使用现代桌面，或选择“全屏缩放”保持 4:3 比例；两者都
保持完整原版功能。实验环境可设置 `M1937_UNSAFE_EXPANDED_VIEWPORT=1`
临时开启旧扩展，但不建议普通玩家使用。

### 4. 鼠标仍然不稳定怎么办？

先双击 `启动游戏-窗口模式.cmd`，或在现代启动中心选择“稳定窗口
1024×768（推荐、已验证）”后保存并重新启动。不要在运行中临时切换
全屏；并确认目录内没有其他来源的 `dinput.dll` 或旧版覆盖文件。

产品 DLL 会把系统光标位置换算为原版相对位移，但不包含任何系统光标
移动、锁定或回中的调用。窗口失去前台焦点时，补丁会把鼠标位移和按键
清零，避免游戏在后台继续响应。关卡选择只预置编号，请从原版菜单点击
“开始游戏”。发布门禁还会拒绝光标捕获/释放和抢前台 API，并在菜单、
场景回归中只读检查 Windows 光标裁剪矩形；出现任何限制样本即判失败。

### 5. 安装器提示主程序版本不匹配

不要跳过校验。本补丁包含针对特定 `M1937.exe` 的内存修复，其他版本需要重新定位和测试。

### 6. 杀毒软件提示未知 DLL

`dinput.dll` 是本项目从源码构建的本地兼容层，没有数字签名。源码位于本包 `source\dinput-proxy`，便于审查和重新构建。测试机上的 Windows Defender 扫描未发现威胁。不要因此给整个游戏目录设置永久杀毒排除项。

### 7. 仍在切换关卡时短暂停顿

大型关卡资源从机械硬盘首次读取时可能出现正常加载等待。若只发生在关卡切换，可把完整游戏目录复制到 SSD；不要只移动个别资源文件。

v1.4.1 已把性能遥测写盘移出 DirectInput/消息泵：快照进入固定容量队列，
由低优先级后台线程写入。正式四组 10 分钟共 38,739 个采样，未响应和
超过 50ms 的卡顿均为 0，P99 为 9.414–12.837ms，输入与消息泵最大值
分别为 7.007ms 和 9.979ms，遥测丢失为 0。完整结果见
`MOD性能与AI回归验收报告.md`。
